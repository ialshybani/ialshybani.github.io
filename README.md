# Ibrahem A. Alshybani — Academic Website

Static academic website for GitHub Pages at `https://ialshybani.github.io`.

## Deploy using GitHub's website

1. Create the public repository `ialshybani/ialshybani.github.io` (if not already created).
2. In the repository, select **Add file → Upload files** and upload `index.html`, `styles.css`, and `script.js` to the repository root. (Do not upload the ZIP file itself.)
3. Select **Commit changes**.
4. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Choose branch `main` and folder `/(root)` and save.
5. After deployment completes, visit `https://ialshybani.github.io`.

## Personalize

- Edit `index.html` to change biography, publication statuses, and links.
- Add an approved portrait later if desired.
- The full supplied résumé was intentionally **not** included because it contains a personal phone number. Before publishing a CV, create a public-safe version and link it from the contact or navigation sections.
- This is a personal website, not an official Purdue University site.
- Styles load Google Fonts; they fall back to local fonts if unavailable.
